# ArtHub OS Master Prompt v3.0 — SMM Telegram automation (2026-11-14)

Продолжение v2.9. Не создавать новый сайт, не менять main, дизайн, цены, факты. Разделить публикации Threads и информационную SMM-тему.

Существующий бот @arthub_tbilisi_admin_bot: личные диалоги работают; входящие сообщения из групп игнорируются; исходящие в тему SMM · Instagram допускаются через Telegram Bot API. Не убирать private-only guard в doPost.

Канонический реестр для новой очереди: Google Sheet ArtHub OS — Threads / вкладка «SMM · Telegram» (лист id 844260183), столбцы A-H: ID события / Статус / Готовый пост Instagram / Фото URL / Информация TG / Пост TG / Фото TG / Ошибка.

Рабочий принцип:
1. Каждые 15 минут фоновый таймер существующего Google Apps Script (после однократной установки пользователем) сверяет вкладку «События» с очередью.
2. Каждое новое событие с названием и описанием добавляется в очередь со статусом «Черновик» и автоматически собранным текстом-шаблоном. Шаблон не выдавать за вручную отредактированный авторский пост.
3. Только строка со статусом «Согласовано» и заполненным постом может отправляться. Два отдельных исходящих сообщения: полная информация (из реестра событий, со ссылками/сведениями), готовый текст Instagram. Информация/пост фиксируются отдельно с Telegram message_id. При неопределённом результате — не повторять автоматически.
4. Дополнительно разрешён третий объект — изображение по прямой публичной HTTPS-ссылке в «Фото URL», если его подготовили люди. Художественные материалы и визуальное оформление остаются на усмотрение команды; никакого поручения кому-либо.
5. Instagram НЕ публикуется автоматически. Telegram SMM — информационный поток, не канал заданий и контроля.
6. Соблюдать правила оформления из «Правила редакции»: без Markdown и bold; минимум эмодзи; 📅 дата и время; лектор и язык рядом без эмодзи; 🎟️ цена; 📍 адрес; «Запись и подробности — @arthub.tbilisi».
7. E003/E004 внесены в очередь как «Согласовано». Если предыдущий разовый тест отправки этих лекций был реально выполнен, перед запуском новой очереди сверить результаты и отметить отправленные сообщения, иначе возможны дубли.

Файл для переноса: ArtHub_SMM_auto_sync.gs. Функции установки arthubSmmInstallAutomation(), немедленной обработки arthubSmmRunNow(), отключения arthubSmmPauseAutomation(). Script Property ADMIN_BOT_TOKEN уже есть в существующем проекте. Не публиковать токен. Не нужно повторно Deploy, потому что trigger и ручной запуск исполняются непосредственно из редактора, webhook остаётся существующим.
