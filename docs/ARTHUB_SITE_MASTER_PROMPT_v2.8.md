## Instagram · утверждённые правила оформления готовых публикаций
1. Строго обычный текст без Markdown-жирного, HTML-bold и подмены символов Unicode-bold; готовый текст должен вставляться в Instagram без дополнительной обработки.
2. Эмодзи по минимуму, для навигации по практической информации, не для декора.
3. Дата и время обязательно одной строкой, обозначенной одним календарём: «📅 16 ноября, 20:00». Не использовать отдельный часовой эмодзи.
4. «Лектор — Ксения Липская» и «Язык — русский» расположить рядом, без эмодзи у обеих строк. Можно объединить.
5. Цена/стоимость только с эмодзи билета «🎟️», никогда с 💰, 💸 и прочими финансовыми эмодзи.
6. Указывать полный адрес «📍 ArtHub Tbilisi, 172 Davit Aghmashenebeli Ave, Tbilisi» и прямую контактную строку «Запись и подробности — @arthub.tbilisi».
7. При передаче SMM-материалов по запросу создавать два отдельных сообщения: (а) полная исходная информация и проверенные факты, (б) готовый для копирования Instagram-пост. Избегать названия «задание Маше» и любых управленческих указаний.
8. Реестровые факты и описания сохранять максимально близкими к источнику, не выдавать отредактированный текст за оригинальную авторскую цитату.
