## Что делает владелец сейчас

1. В уже открытом Google Apps Script нажмите **+** рядом с «Файлы» → «Скрипт». Назовите новый файл `PublicEventsFeed`. Старый календарный код не удаляйте.
2. Скопируйте весь текст из [PublicEventsFeed.gs](../automation/PublicEventsFeed.gs) и вставьте в новый файл.
3. Нажмите «Сохранить», выберите `previewPublicEvents` → «Выполнить».
4. В журнале должно быть `Public events count: 0` (пока все строки со статусом «Не публиковать»). Если иначе — остановитесь, пришлите ошибку.
5. Затем **Развернуть → Новое развертывание → Веб-приложение**; «Выполнять от имени: я», «Доступ: все» (Anyone) — это необходимо для публичного сайта. Скрипт выдаёт только явно одобренные события, не всю таблицу.
6. Передайте `https://script.google.com/macros/s/…/exec`. Никогда не передавайте код доступа, пароль, токен или ключ.

## Что делает помощник после URL

1. Проверить, что /exec возвращает корректный JSONP `window.arthubReceiveEvents(...)` без личных и внутренних полей.
2. Внести подтверждённый URL в `events/live-events-config.js`.
3. Проверить скрипт на примере E003, не меняя публично данные без согласования.
4. Проверить RU/EN, мобильную версию, отсутствие дублей, и отсутствие Open Residency.
5. После проверки объединить PR с `design/blue-lime-editorial`; проверить Cloudflare и общедоступный сайт.
6. Дать пользователю тест «Изменить название в W=Опубликовать и проверить публичную карточку»; затем вернуть проверочный текст.

## Важные ограничения

- Публичная выдача через Apps Script JSONP запускает доверенный JS из публичного endpoint. Использовать только контролируемое пользователем развертывание; не размещать посторонние URL.
- Нельзя скрыть существующие вручную созданные карточки только установкой W=Не публиковать: до миграции они остаются на странице. Процесс снятия с публикации нужно завершить отдельно.
- Изображения автоматически пока не выбираются: используется одобренная графика сайта ArtHub.
- Обновления из таблицы отображаются только после обновления страницы посетителем; непосредственного перезапуска Cloudflare для содержания карточки не требуется после развертывания.
- Два языка обязательны для публикации, чтобы не выводить машинный русский текст под английским переключателем.
